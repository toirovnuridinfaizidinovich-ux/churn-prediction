# Churn Prediction

## Live demo

[Открыть приложение](https://churn-prediction-e6qcvjerclxsjycdylkver.streamlit.app/)

Загрузите CSV с данными клиентов, чтобы получить:

- вероятность оттока — `churn_probability`;
- решение модели — `churn_label`;
- сегмент риска — `high`, `medium` или `low`;
- готовый CSV с прогнозами для скачивания.

ML-приложение для прогнозирования оттока клиентов телеком-компании.

Пользователь загружает CSV-файл с данными клиентов. Модель оценивает вероятность оттока, присваивает метку churn и сегмент риска. Результат можно посмотреть в браузере и скачать как CSV.

## Возможности

- Загрузка CSV-файла с клиентами
- Прогноз вероятности оттока для каждого клиента
- Метка `churn_label`:
  - `1` — клиент с высоким риском ухода
  - `0` — клиент с низким риском ухода
- Сегментация риска:
  - `high` — вероятность оттока от 0.70
  - `medium` — от 0.40 до 0.69
  - `low` — ниже 0.40
- Сортировка клиентов: самые рискованные находятся сверху
- Скачивание готового CSV с результатами

## Запуск

### 1. Клонировать репозиторий

```bash
git clone [https://github.com/toirovnuridinfaizidinovich-ux/churn-prediction.git](https://github.com/toirovnuridinfaizidinovich-ux/churn-prediction.git)

```


### 3. Запустить интерфейс

```bash

```

После запуска открой в браузере:


## Использование

1. Открой интерфейс Streamlit в браузере
2. Загрузи CSV-файл с клиентами
3. Нажми `Сделать прогноз`
4. Посмотри клиентов с высоким, средним и низким риском
5. Скачай CSV с результатами

## Результат

В итоговую таблицу добавляются три столбца:

| Столбец | Описание |
|---|---|
| `churn_probability` | Вероятность ухода клиента: число от 0 до 1 |
| `churn_label` | Решение модели: `1` — риск оттока, `0` — низкий риск |
| `risk_segment` | Сегмент риска: `high`, `medium` или `low` |

Пример:

| churn_probability | churn_label | risk_segment |
|---:|---:|---|
| 0.805 | 1 | high |

Это означает, что модель оценивает риск ухода клиента примерно в 80.5%.
